# CineScope 固定浅色视觉规范

## 目标与边界

- 目标用户：需要快速浏览近期影视、按条件筛选并查看详情的中文用户。
- 核心任务：选择分类，搜索或筛选作品，查看详情、预告片与分享图。
- 改造模式：视觉全面重构，信息架构和业务契约保持不变。
- 技术边界：继续使用原生 ES Modules、静态 Pages 和生成 JSON，不引入框架或运行时依赖。
- 数据边界：分类 ID、Hash URL、JSON 结构、数据更新任务、豆瓣同步和分享 URL 均保持不变。
- 前后台一致性：项目没有后台页面，此项不适用。

## 美术方向

一句话主张：把动态影视目录做成一张可以浏览和操作的电影编辑白纸。

- `DESIGN_VARIANCE 7`：Hero 使用错位三行标题和独立插画，内容区回到稳定单轨。
- `MOTION_INTENSITY 8`：标题、插画和章节一次性编排，指针与滚动只产生轻微位移。
- `VISUAL_DENSITY 4`：保留真实海报和必要指标，以留白和细分隔线组织内容。
- 固定浅色：全站始终使用 `#FFFFFF`、`#1A1A1A`、`#FFE28A`，不提供深色模式、系统跟随或主题切换。
- 纸面纹理：32px 低对比网格与黄色径向洗色只作为背景层，不承载信息。
- 字体：系统无衬线用于正文与标题，系统等宽用于日期、评分和状态元数据。
- 圆角角色：卡片 20px、媒体 15px、控件 10px、标签 999px。
- 页面轨道：内容宽度 820px，桌面左右留白 32px，移动端 20px。

## 首屏与生成资产

- Hero 标题固定为“鲤鱼 / 环球 / 片单”三行，桌面约 86svh，移动端约 74svh。
- 唯一主动作“浏览片单”直接定位分类与筛选区。
- 简介、数据更新时间和豆瓣同步状态继续显示真实运行数据。
- `assets/illustrations/cinescope-koi-film.png` 用于 Hero：鲤鱼环绕胶片卷与放映机的近黑编辑线稿，黄色强调，无文字、人物或 Logo。
- 资产由内置图像生成模式创建，源图使用纯绿色色键背景，再通过本地软边、去色溢和 1px 边缘收缩转为透明 RGBA PNG。
- favicon 保留原有 C 形轨道、播放符号和圆角底板结构，只使用黑、白、黄平面色。

## 分类、筛选与卡片

- 分类是 Hero 下方始终可见的单行标签导航，手机端横向滚动，不使用重复分类弹层。
- 桌面直接显示搜索、评分和类型；760px 及以下使用底部筛选面板。
- 状态信息通过 `loading`、`empty`、`error`、`success` 语义 token 呈现。
- 卡片常态无阴影，精细指针桌面只抬升海报媒体；触屏不依赖 hover。
- 卡片列数：大于 760px 三列，360px 至 760px 两列，小于 360px 单列。
- “查看详情”始终可见，预告片按钮保持独立，键盘入口、分页、年份定位和渐进加载继续可用。

## 动效与降级

- 默认 HTML 完整可见，JavaScript 成功启动后才添加动效状态。
- 标题同组错峰为 80ms，最大延迟 480ms；只动画 `transform` 与 `opacity`。
- `IntersectionObserver` 负责章节的一次性进入；全局仅保留一个 passive scroll 监听，并在 RAF 中更新年份、无限加载、返回顶部、Hero 位移和阅读进度。
- 指针联动上限为横向 8px、纵向 6px，仅在精细指针、Hero 可见、页面可见且未开启减弱动效时运行。
- `prefers-reduced-motion` 下取消位移、背景漂移、级联动画和平滑滚动，内容直接处于最终状态。
- 系统深色偏好下仍显示固定白纸界面。
- 禁用 JavaScript 时可完整看到品牌首屏和恢复提示；动态片单、筛选和详情依赖 JSON 加载，因此不可用。

## 详情、预告片与分享

- 详情抽屉、移动端全屏详情、筛选面板、Toast 和分享预览统一使用白纸黑墨体系。
- 预告片播放器保留近黑媒体表面，弹层其余区域使用固定浅色。
- 详情只展示真实评分、日期、导演、主演、平台和外部链接，不生成虚假片单编号。
- Bilibili 预告片标题在数据标准化阶段移除残留 HTML 标签，最终仍使用 `textContent` 渲染。
- 分享画布使用白纸、32px 细网格、黑墨和黄色强调，继续保留海报、真实指标、二维码失败回退与系统分享流程。
