# CineScope 纸墨电影编辑首页简报

## 目标与范围

- 将原有深色筛选工具页重组为暖白纸张、深墨文字与金色强调的电影编辑首页。
- 首屏先建立品牌与内容发现语境，再呈现今日推荐、影讯、编辑札记、年份时间线和类型浏览；完整片单进入独立路由。
- 保留静态 HTML、原生 ES Modules、生成 JSON、筛选、分页、详情、分享、豆瓣状态和预告片能力。
- 首页、影讯、影评、片单和关于本站使用可直接刷新的静态路径；分类使用片单下的真实子路由。
- 不引入框架、后端、数据库、评论系统、外部内容采集或浏览器端伪订阅。

## 视觉方向

一句话主张：像翻阅一册当日更新的电影志，在纸墨留白中进入真实片单，在深色影院表面中观看预告。

- 页面背景使用暖白纸张色，正文使用深墨色，边界以低对比细线表达。
- 标题采用中文衬线字体，操作与数据采用无衬线字体。
- 金色是唯一品牌强调色，用于品牌圆点、选择态、主按钮和关键数值；不使用默认红色印章色。
- Hero 和页脚保持炭黑与暖金电影感；详情抽屉为浅色编辑面板；预告片播放器保持深色。
- 卡片阴影轻微，不使用霓虹、扫描线、故障字、重度玻璃拟态或无目的 3D。

## 内容与交互规则

- 顶部导航使用 `/`、`/news/`、`/reviews/`、`/catalog/`、`/about/` 静态路径，不使用页面锚点模拟栏目切换。
- 分类使用 `/catalog/{category}/` 子路由；`/catalog/` 默认展示国产剧。构建阶段为每个已配置分类生成目录，确保 GitHub Pages 直接访问与刷新可用。
- 今日推荐最多 4 项：优先当前分类即将上映作品，再按已验证评分和日期补齐；缺失海报的作品不进入推荐位。
- 影讯和编辑札记来自 `content/editorial.json`，点击后加载对应分类并打开真实作品详情。
- 首页时间线展示默认分类的实际年份作品数和最多 4 张真实海报；点击进入片单路由并定位对应年份。
- 首页类型浏览展示默认分类优先级最高的 8 个真实类型及数量；点击进入片单路由并带入类型筛选。
- 完整片单的分类、评分、类型、搜索、分页与年份时间线全部收拢到片单路由。
- Top250 在桌面端使用固定宽度卡片，少量结果不会拉伸。
- 订阅默认禁用并明确显示“订阅暂未开放”；只有配置 HTTPS 表单端点后才允许提交。
- 手机端保留分类面板和底部筛选面板，首页内容改为单列或横向推荐流。

## 验收基线

- 内容校验覆盖必填字段、唯一 ID、合法日期、HTTPS 端点、作品引用和本地图片。
- 单元测试覆盖推荐不足 4 项、无评分、重复、缺图、空分类和年份分组。
- 工程检查：`git diff --check`、`npm run check`、`npm run build:site`。
- 静态产物通过 HTTP 检查首页、内容页、片单入口、全部分类子路由、Hero、编辑内容 JSON、入口脚本和关键海报。
- 本轮不包含浏览器截图、点击和多尺寸视觉 QA；视觉验收需在后续获得明确授权后单独执行。
