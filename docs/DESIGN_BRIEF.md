# CineScope 固定浅色视觉规范

## 目标与边界

- 目标用户：需要快速浏览近期影视、按条件筛选并查看详情的中文用户。
- 核心任务：选择分类，搜索或筛选作品，查看详情、预告片与分享图。
- 改造模式：视觉全面重构，业务能力、数据契约和 Hash URL 保持兼容，导航与布局可按任务重构。
- 技术边界：继续使用原生 ES Modules、静态 Pages 和生成 JSON，不引入框架或运行时依赖。
- 数据边界：分类 ID、Hash URL、JSON 结构、数据更新任务、豆瓣同步和分享 URL 均保持不变。
- 前后台一致性：项目没有后台页面，此项不适用。

## 美术方向

一句话主张：把动态影视目录做成一张可以浏览和操作的电影编辑白纸。

- `DESIGN_VARIANCE 6`：紧凑目录题头保留标题与插画识别，内容区使用稳定单轨。
- `MOTION_INTENSITY 4`：题头和章节只做一次性短编排，不使用指针跟随或滚动视差。
- `VISUAL_DENSITY 6`：打开页面后尽快进入分类、筛选和真实海报，以细分隔线组织信息。
- 固定浅色：全站始终使用 `#FFFFFF`、`#1A1A1A`、`#FFE28A`，不提供深色模式、系统跟随或主题切换。
- 纸面纹理：32px 低对比网格与黄色径向洗色只作为背景层，不承载信息。
- 字体：系统无衬线用于正文与标题，系统等宽用于日期、评分和状态元数据。
- 圆角角色：卡片 20px、媒体 15px、控件 10px、标签 999px。
- 页面轨道：内容宽度 1100px，桌面左右留白 32px，移动端 20px。

## 规范来源与采用

- 手机布局采用日期：2026-10-03。
- 通用真源：[响应式设计](../../project-standards/design/responsive-design.md)、[UX 与交互](../../project-standards/design/ux-interaction.md)、[可访问性](../../project-standards/design/accessibility.md)。
- 项目设计稿记录当前方案；导航位置、卡片列数与断点不是永久业务约束。再次要求按最新规范重构时，先读取通用正文并检查本稿是否滞后。
- 参考 Atlas 的导航收纳与阅读结构，不复制其主题、底栏、模拟状态栏或样例内容。

## 导航与内容布局

- 桌面保留紧凑题头、横向分类和展开筛选；插画低优先级加载。
- 手机底栏依次为剧集、电影、综艺、搜索、关于；顶栏显示当前部分与筛选入口。
- 剧集进入国产剧，顶部子分类为国产剧、韩剧、日剧、美剧；电影进入院线电影，子分类为院线电影、豆瓣Top250；综艺只有一个分类，不显示顶部子分类行。移除左侧分类抽屉。
- 搜索通过底栏进入，显示当前分类的搜索框和取消按钮；主界面不常驻搜索框。评分和类型统一在右侧筛选栏，保留原筛选语义、选中标记、关闭与浏览器返回。
- 关于收纳站点名称、原有标题、说明、片单更新时间与豆瓣同步状态，使用真实数据，不另造时间戳。
- 底栏按实际高度给内容及返回顶部按钮留出空间，避让安全区；详情和筛选浮层打开时隔离背景导航。
- 时间分组和顺序明确的网格保持不变；手机最多双列，最小卡片宽度约 9.5rem，窄屏或字体放大回退单列。标题完整显示，不靠缩小正文维持列数。
- 海报保留 2:3 比例、加载尺寸与失败回退；触屏详情及预告片入口始终可见。
- 外层页面负责滚动，网格负责排版；局部横向滚动保留发现线索，最后一张卡片完整可达。

## 详情、预告片与分享

- 手机详情使用全屏阅读页，顶栏只有返回和分享，作品标题在正文呈现；返回恢复片单筛选与滚动位置。
- 正文采用独立阅读字号、行距和边距，真实元数据与剧情保持原文。
- 返回按钮、浏览器历史与增强手势共用关闭语义。详情及右侧筛选采用左侧内缩 24–56px 起手区域，仅向右拖动；保留最左侧系统手势区域，正文滚动及横向媒体不接管。起点与宽度固定，主方向确认后才拖动；反向、多指、取消、选区、视口变化、页面隐藏及导航中断不执行返回。完成距离为 max(72px, 面板宽度的 25%)，此项目阈值仍须真机校准。
- 详情与筛选面板支持 Escape、焦点循环、背景隔离和滚动锁；关闭恢复触发位置。
- 预告片保留近黑播放器与浅色弹层，分享画布继续使用黑白黄与真实数据。
- 顶栏、抽屉和面板避让安全区；面板内容独立滚动，关键返回与关闭操作保持可达。

## 动效与降级

- 保留一次性短动效，不引入持续动画、滚动视差或指针跟随。
- 减弱动效下导航、片单和弹层立即落到最终状态；手机插画维持次级层级。
- 系统深色偏好下仍显示固定浅色；禁用 JS 时保留题头和恢复提示。

## 运行态验收矩阵

| 视口 / 场景 | 导航与筛选 | 片单 | 详情 |
| --- | --- | --- | --- |
| 320px | 顶栏子分类、五项底栏、搜索入口、右侧筛选 | 单列 | 全屏，返回与分享 |
| 390px | 同上，评分与类型侧栏独立滚动 | 双列 | 同上 |
| 768 / 1024 / 1440px | 桌面题头、分类与筛选 | 三列 | 抽屉 |
| 200% 文本 | 操作仍可达，长文本换行 | 按可读宽度回退单列 | 正文及顶栏不溢出 |
| 横屏 / 矮可视区域 | 抽屉、搜索和筛选可关闭 | 外层滚动，末尾可达 | 返回不被遮挡 |

交互覆盖分类选择与浏览器返回、搜索、评分与类型清空、渐进加载、详情返回与焦点循环、预告片和分享。异常覆盖无结果、媒体失败、长标题、浅色偏好、减弱动效和禁用 JS。

验收报告必须区分浏览器渲染、可视区域模拟与真机；软键盘、系统手势及安全区未经真机检查不得宣称已通过。

- 交互：7 个分类、抽屉 Escape/浏览器返回、搜索、评分、类型清空、详情返回和焦点恢复通过；Top250 渐进加载至 250 项，末尾详情按钮可达且不被浮动工具遮挡。
- 弹层与回退：预告片弹层关闭、分享预览及其 Escape/浏览器返回、二维码与海报失败回退通过。外部请求在回退检查中主动阻断，不代表实际视频或二维码服务验收。
- 无障碍抽查：键盘打开/关闭分类、ARIA 树中的名称与选中状态、高对比模拟通过；抽查卡片标题、元数据、评分及顶栏标题的白底文字对比度至少 6.09:1。
- 未验证：真机 Safari、软键盘、系统字体设置、系统手势及安全区、真实读屏、系统分享、实际外部播放和线上部署。视口与根字号模拟不能替代设备证据。

## 手机交互修复验收（2026-10-03）

- 依据：当前通用 UX 文档的「滑动返回判定与生命周期」，并核对响应式及可访问性正文。
- 根部固定底栏不跟随 visualViewport 键盘补偿平移；输入且可视高度明显缩小时暂时隐藏底栏，内容保留实际导航高度留白。详情单一滚动容器，内容不 flex 收缩；背景锁定保存列表位置，关闭恢复。
- Computer use：线上检查与本地修复回归，七个分类、评分及类型清空、搜索取消、关于、详情底部向上滚动、短滑动回弹、完成手势返回、详情/预告片/分享的嵌套前进后退均检查。播放器用新 iframe 实例加载及卸载，避免空地址导航干扰主页面历史。
- 长列表实际滚动至 Top250 的 250 项，末尾详情按钮低于内容区底栏遮挡边界之前；320、390、768、1024、1440px、740×390 横屏及 390×480 矮屏无页面横向溢出。200% 根字号临时测试页面下，搜索取消、右侧筛选与完成操作仍可达。
- 分享：并发加载海报与二维码，每次图片请求 2 秒超时，外部代理回退也有 2 秒超时；生成期间有反馈，离开原详情后不会交付过时结果。手机宽度的桌面浏览器采用图片预览，实际手机的系统分享保留能力检测。
- 未验证：真实手机 Safari、软键盘、系统返回与安全区、系统字体和真实读屏、实际系统分享。Computer use 的拖动属于桌面指针输入，不能替代真实多指和系统边缘手势证据；播放器已验证容器与导航，外部 B 站脚本存在请求错误，不代表视频服务完整验收。
