# iOS UI / UX 验收记录

验证日期：2026-10-17（Asia/Shanghai）。本轮仅修改原生 iOS 界面、对应交互和设计说明，不修改线上 JSON、网页布局、签名设置或发布流程。

## 采用依据

- 项目品牌与业务基线：`../docs/DESIGN_BRIEF.md`。
- 当前通用规范：`../../project-standards/design/` 下的 `responsive-design.md`、`ux-interaction.md`、`accessibility.md`、`motion-and-performance.md`、`visual-style.md`、`color-and-theme-modes.md`。
- 按原生平台适配：NavigationStack 负责返回与层级，系统分享负责交付；浏览器 Hash、DOM 焦点循环、网页双指缩放和 CSS 视口不作为 SwiftUI 实现要求。

## 变更范围

发现页合并品牌与分类，缩减固定区域；类型筛选进入独立面板，保留即时评分与结果数量。海报取消外围卡片框，评分叠在海报下角，片名完整换行。详情保留真实元数据，前置预告片主入口，扩大阅读字号和行距。收藏采用纸质票根，搜索扩大海报和输入命中区。

标签页首次访问后保留实例，保留搜索、导航与滚动上下文；隐藏页隔离点按和辅助技术。改变筛选时显式定位列表顶部，修正搜索评分标签误读发现页评分的问题。收藏状态在首页独立加载，避免必须先进入「我的」才出现徽标。

动效只作用于按压、选中和图片加载：约 240ms 的小幅按压、260ms 的选中变化与 180ms 海报淡入。底栏通过 matched geometry 移动黄色选中胶囊；没有循环、错峰、持续模糊或滚动特效。减弱动效与减少透明度保留源码降级路径。
